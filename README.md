# B 站白噪音 · iPod 播放器

把 B 站视频做成白噪音播放器，套一个 iPod Classic 的壳，可嵌入 Notion 当背景音面板。单文件、零依赖、纯静态。

**在线预览：**
- GitHub Pages：https://xyltypearl-del.github.io/bilibili-white-noise/
- WorkBuddy：https://bilibili-white-noise.app.workbuddy.host/?sharecode=VG6LDUKH7L

---

## 功能

- **iPod Classic 造型**：白色机身 + 圆形点击转盘 + 黑边屏幕
- **两级菜单**：主题列表 → 曲目列表 → 正在播放（屏幕内嵌 B 站画面）
- **主题分组**：6 个主题，可单独嵌入 Notion
- **循环模式**：主题内轮播 / 单曲循环 / 手动，附带定时切换（30/45/60/90/120 分钟）
- **多分 P 支持**：视频链接带 `&p=2` 时，曲目加 `page: 2` 即播第 2 P
- **透明背景**：嵌入 Notion 时无违和衬底
- **逐级返回**：屏幕左上角 `‹` / 转盘 MENU / 键盘 Esc
- **深链**：用 URL 参数直达某个主题或直接播放

## 操作方式

| 动作 | 转盘 | 键盘 | 屏幕 |
|---|---|---|---|
| 上下选曲 | 在圆盘上上下拖动（每 15° 一格） | ↑ / ↓ | 点列表项 |
| 确认 / 播放 / 切循环模式 | 按中心 SELECT | Enter | — |
| 返回上一步 | 按 MENU | Esc | 左上角 `‹` |
| 切上一首 / 下一首 | 按 ◀ / ▶ | ↑ / ↓ | — |

进入「正在播放」后，屏幕就是 B 站播放器，**播放 / 暂停 / 音量用画面内 B 站自带控件**。

### 循环与定时

播放页顶部有两个小标签：

- 左边「模式」循环切换：
  - **主题**：本主题内顺序循环，播到末首回到首首
  - **单曲**：重复当前这一首（强制重载，从头播）
  - **手动**：不自动切换
- 右边「每 N 分」循环切换间隔：30 / 45 / 60 / 90 / 120 分钟，默认 45

◀▶ 和转盘换曲都只在**当前主题内**循环，不会跳到别的主题。

## 嵌入 Notion

Notion 里输入 `/embed`，粘贴页面地址即可。建议高度约 520px，刚好露出整个 iPod。

### 分主题嵌入

在地址后加参数，每个主题可以单独做成一个 embed 块：

```
.../?theme=zen                 直接进「禅院钟声」曲目列表
.../?theme=zen&auto=1          直接进并播放该主题第一首（自动轮播）
.../?theme=study&auto=1        陪伴学习主题，直接播放
.../?v=BV14y4y1h7FG            按 BV 号直接播放
.../?t=0                       按曲目序号直接播放（兼容旧版）
```

可用主题 id：`all` / `zen` / `rain` / `game` / `study` / `life`

这样可以在 Notion 里分别摆「专注墙 / 助眠墙 / 陪伴墙」，各自轮播。

## 自己改歌单

所有内容都在 `index.html` 顶部。用文本编辑器打开即可，不需要懂前端。

### 加一首

在对应主题的注释下方，复制一行改两个地方：

```js
{ title: "曲名", bvid: "BVxxxxxxxx" },
```

- `title`：列表里显示的名字，小屏幕建议 10 字以内
- `bvid`：B 站视频页地址里 `BV` 开头那串，例如 `https://www.bilibili.com/video/BV14y4y1h7FG` 取 `BV14y4y1h7FG`
- 每行**末尾的逗号别丢**

### 加分 P 视频

链接带 `&p=2` 就加 `page: 2`：

```js
{ title: "曲名", bvid: "BVxxxxxxxx", page: 2 },
```

### 删一首 / 调顺序

整行删掉即可；`TRACKS` 数组里的先后顺序就是列表从上到下的顺序。

### 加一个新主题

先在 `THEMES` 里加一行，再给曲目标上同样的 `theme`：

```js
const THEMES = [
  { id:'all',   ico:'全', name:'全部曲目' },
  { id:'zen',   ico:'禅', name:'禅院钟声' },
  // 新增主题 ↓
  { id:'new',   ico:'新', name:'新主题' },
];

// 曲目里加 theme:'new'
{ title: "曲名", bvid: "BVxxxxxxxx", theme:'new' },
```

改完存盘，重新上传到 GitHub（或让我重新发布 WorkBuddy 版），页面自动更新。

## 已知限制

1. **首次必须手动点一下播放键**。浏览器禁止无用户交互的自动播放，这是硬限制；点过一次后切歌基本能续上。
2. **轮播是按设定时长到点切歌，不是播完再切**。B 站播放器是跨域 iframe，网页读不到视频的播放进度和结束事件。建议把「每 N 分」设成约等于视频时长。定时切歌后可能需要补点一下画面才出声。
3. **音量只能用 B 站播放器自带的条调**。同样是跨域限制，外层网页控制不了内层 iframe 的音量。
4. **离开页面音频会停**。Notion 的 embed 是内联的，切走该页面声音就断，不会像系统级白噪音那样常驻后台。要全天候常驻得做成浏览器扩展。
5. **少数 B 站视频不能嵌**。带版权或区域限制的视频在 iframe 里会提示「无法在当前页面播放」，挑能正常外链播放的环境音视频即可。

## 部署

纯静态页面，任何静态托管都行：GitHub Pages / Vercel / Netlify / WorkBuddy 一键发布。

### 部署到 GitHub Pages（踩坑提醒）

1. 仓库：`xyltypearl-del/bilibili-white-noise`
2. Settings → Pages → Source 选 **Deploy from a branch**，Branch 选 `main`，目录 `/(root)`
3. 上传或改文件时，**文件名必须精确为 `index.html`**，一个空格、一个 `v2` 都不能多——Pages 只认这个名字，写成 `index v2.html` 就是白传
4. 拖完文件**必须滚到页面最底部点绿色 `Commit changes`** 才会真正保存。只拖进去看到绿色对勾就关页面 = 没提交，这是"传了几次还是旧版"的头号原因
5. 等 1~2 分钟 Pages 自动重建
6. 验证别靠浏览器缓存页面肉眼猜，直接看仓库 `index.html` 的字节数或 SHA 是否变了；打开时用无痕窗口或 `?v=随机数字` 破缓存

### 本地预览

直接双击 `index.html` 用浏览器打开即可。但本地 `file://` 和 `localhost` 地址**不能嵌进 Notion**（Notion 在云端访问不到），嵌 Notion 必须用公网地址。
